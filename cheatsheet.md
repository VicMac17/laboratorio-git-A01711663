git status: Muestra el estado del repositorio, si está actualizado respecto al GitHub o si hubo modificaciones.

git add: para preparar archivos antes del commit y push.

git commit: es para registrar los cambios en el repositorio y agregar una descripción de lo que se hizo en esos cambios.

git push: actualiza finalmente los cambios realizados en el repositorio.

git pull: toma todos los archivos modificados o nuevos desde el repositorio hacia la computadora personal, en otras palabras actualiza lo que tienes en la computadora a la versión más reciente del repositorio. 

git log: es para ver un historial de commits.

git diff: muestra las diferencias entre el archivo guardado actual y el que cambiaste despupes de hacer git add. 

git restore: regresa la anterior versión guardada de un archivo según la última vez que se hizo commit y descarta cualquier cambio.

git restore --staged: no se borran los cambios a nivel local pero ya no están preparados para el commit.
